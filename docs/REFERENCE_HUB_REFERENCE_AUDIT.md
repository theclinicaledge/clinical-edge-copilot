# Reference Hub editorial reference audit

Date: 2026-10-20 (Pacific). Scope: all 60 topics, six pathways, five concepts, their connections, example intervals, teaching copy, source access, and compact interactions. Review base: c2398e1; integrated with newer main c6728fc before release. Branch: codex/reference-hub-review.

This is a reference-informed editorial and software review, not independent clinical validation, bedside testing, or clinician/pharmacist sign-off. The recorded clinical validation registry was not changed. The UI explicitly states that independent clinician review has not been completed for this revision. No diagnostic engine, treatment instructions, medication doses, or ventilator settings were added.

## Review approach

Read every existing topic and pathway/concept field. Compared clinical claims with the named guideline, laboratory, instrument, or clinical-reference sources below. Corrected causal overstatements, universal targets, assay/measurement assumptions, diagnostic shortcuts, and delay-implying text. Adult laboratory examples are explicitly distinguished from individualized goals and the reporting laboratory's intervals. Synthetic arithmetic examples only. Existing topic IDs, titles, categories, aliases, and all related-reference links were preserved.

The 2012 finalized KDIGO AKI criteria were used; the KDIGO site described the 2026 update as a public-review draft at access. SSC 2026 was available from SCCM. ARDS intubated oxygenation severity boundaries follow the 2024 global definition and are not presented as a standalone diagnosis. Source publication year is not a claim of clinician review of this app.

## Pathways and concepts

All six pathways now connect multiple plausible explanations with the bedside findings, instead of implying one inevitable causal sequence. Each has one optional two-choice reasoning check and explanatory feedback, inside the existing common-pattern card. Connect-the-clues separators are neutral rather than arrows implying universal causation. Sources and checks start collapsed.
